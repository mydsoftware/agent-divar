# مهاجرت امن داده‌های نسخه قدیمی

## رفتار نسخه اجرایی

در اولین اجرای نسخه بسته‌بندی‌شده، برنامه پوشه `data` کنار فایل اجرایی را به‌عنوان منبع احتمالی نسخه قدیمی بررسی می‌کند و داده‌ها را به مسیر کاربر منتقل می‌کند:

`%LOCALAPPDATA%\AgentDivar\data`

موارد پشتیبانی‌شده:
- `leads.sqlite3`: تهیه snapshot با SQLite Backup API و کنترل `PRAGMA integrity_check`
- `settings.json` و `browser-session.json`
- پوشه `property-media`
- پوشه `browser-profile`

## تضمین‌های محافظتی

- فایل مقصد موجود هرگز بازنویسی نمی‌شود.
- فایل منبع حذف یا جابه‌جا نمی‌شود؛ عملیات کپی است.
- فایل‌های رسانه و پروفایل به‌صورت جداگانه و فقط در صورت نبودن مقصد کپی می‌شوند.
- پیوندهای نمادین از مهاجرت کنار گذاشته می‌شوند.
- پایگاه‌داده ناسالم منتشر نمی‌شود و خطای مهاجرت آشکار خواهد بود.
- اجرای دوباره مهاجرت امن است و فایل‌های موجود را جایگزین نمی‌کند.

## پیش از به‌روزرسانی

با وجود غیرمخرب بودن مهاجرت، پیش از تعویض نسخه اجرایی از اطلاعات مهم با ابزار پشتیبان‌گیری برنامه نسخه پشتیبان تهیه کنید. پوشه قدیمی `data` را تا اطمینان از صحت اطلاعات نسخه جدید نگه دارید.
