# راهنمای ساخت و اجرای نسخه اجرایی ویندوز

## ساخت بسته

1. Python 3.11 نسخه ۶۴ بیتی را نصب کنید.
2. پوشه پروژه را در ویندوز باز کنید.
3. PowerShell را در همان پوشه اجرا کنید.
4. دستور زیر را اجرا کنید:

   .\build_windows.ps1

پس از پایان موفق، بسته کامل در مسیر dist\AgentDivar قرار می‌گیرد. این بسته پوشه‌ای است و باید تمام محتویات آن با هم جابه‌جا شوند؛ فقط فایل EXE را جدا نکنید.

## اجرای نسخه آماده

فایل dist\AgentDivar\AgentDivar.exe را اجرا کنید. Python برای اجرای نسخه ساخته‌شده لازم نیست. Chromium در بسته قرار می‌گیرد و در صورت نصب بودن Microsoft Edge، برنامه ابتدا Edge را امتحان می‌کند.

## محل داده‌های کاربر

اطلاعات قابل‌تغییر برنامه در مسیر زیر نگهداری می‌شوند:

%LOCALAPPDATA%\AgentDivar\data

شامل پایگاه‌داده، تنظیمات، تصاویر و مدارک ملک، پروفایل مرورگر و وضعیت نشست است. این مسیر از پوشه برنامه جداست و با جایگزینی نسخه اجرایی حذف نمی‌شود.

## آزمون

ساخت محلی و CI دستور AgentDivar.exe --self-test را اجرا می‌کنند. این آزمون وارد رابط گرافیکی نمی‌شود و با پایگاه‌داده موقت، سلامت بسته و SQLite را بررسی می‌کند.

## نکات انتشار

- خروجی فعلی یک بسته پوشه‌ای (onedir) است؛ نه نصب‌کننده MSI و نه فایل تک‌فایلی.
- برای توزیع، کل پوشه AgentDivar را ZIP کنید یا از Artifact ویندوز GitHub Actions استفاده کنید.
- پیش از انتشار عمومی، اجرای واقعی رابط گرافیکی، باز شدن مرورگر، بازیابی پشتیبان و آنتی‌ویروس روی یک ویندوز تمیز باید دستی بررسی شوند.
