# نصب‌کننده ویندوز Agent Divar

## خروجی‌های انتشار

- فایل Setup: نصب‌کننده گرافیکی ویندوز برای کاربر جاری
- بسته Portable: فایل ZIP شامل کل پوشه برنامه؛ بدون نصب در رجیستری یا ساخت میانبر

## نصب

1. فایل AgentDivar-Setup را اجرا کنید.
2. مسیر نصب پیش‌فرض در پوشه Programs کاربر قرار دارد و نیازی به دسترسی Administrator نیست.
3. در صورت تمایل گزینه ساخت میانبر دسکتاپ را فعال کنید.
4. پس از نصب، برنامه را از منوی Start یا میانبر دسکتاپ اجرا کنید.

## اطلاعات و حذف برنامه

اطلاعات کاربر در مسیر زیر قرار دارند و از پوشه نصب مستقل‌اند:

%LOCALAPPDATA%\AgentDivar\data

حذف برنامه فقط فایل‌های نصب و میانبرها را حذف می‌کند؛ دیتابیس، تنظیمات، رسانه‌ها و پروفایل مرورگر کاربر حفظ می‌شوند. برای حذف کامل اطلاعات، ابتدا از برنامه خارج شوید و سپس در صورت اطمینان پوشه داده را به‌صورت دستی حذف کنید.

## به‌روزرسانی

نسخه جدید را روی همان مسیر نصب کنید. پوشه داده کاربر جایگزین نمی‌شود. پیش از به‌روزرسانی‌های مهم، از تب پشتیبان‌گیری نسخه پشتیبان تهیه کنید.

## ساخت محلی

1. Python 3.11 نسخه ۶۴ بیتی و Inno Setup 6 را نصب کنید.
2. در PowerShell از ریشه پروژه اجرا کنید:

   .\build_windows.ps1

3. فایل Setup و ZIP قابل‌حمل در پوشه dist ساخته می‌شوند.

این پروژه در حال حاضر امضای دیجیتال کد ندارد؛ ویندوز ممکن است برای فایل دانلودشده هشدار ناشر ناشناس نمایش دهد. قبل از اجرا، منبع دریافت و هش فایل را بررسی کنید.
