# آزمون سرتاسری انتشار ویندوز

این مرحله در runner ویندوز GitHub Actions، بسته واقعی Inno Setup را نصب و اجرا می‌کند.

## سناریوهای خودکار

1. نصب بی‌صدا با گزینه‌های نصب کاربر جاری و میانبر دسکتاپ.
2. بررسی فایل اجرایی و میانبرهای منوی شروع و دسکتاپ.
3. اجرای `AgentDivar.exe --self-test` پس از نصب، بدون نمایش رابط گرافیکی و بدون استفاده از پایگاه داده واقعی.
4. ایجاد داده و رسانه آزمایشی در مسیر LocalAppData و نصب مجدد همان بسته برای شبیه‌سازی مسیر ارتقا؛ داده‌ها باید حفظ شوند.
5. حذف نصب و تأیید حذف فایل‌های برنامه همراه با باقی‌ماندن داده‌ها و رسانه‌های کاربر.
6. آزمون مستقل پشتیبان‌گیری و بازیابی SQLite و رسانه‌ها با داده موقت.

## گزارش و محدودیت

گزارش PowerShell به‌صورت artifact با نام `AgentDivar-Windows-E2E-Logs` نگهداری می‌شود. این آزمون در runner تمیز ویندوز انجام می‌شود و جایگزین آزمون نصب روی رایانه واقعی کاربر نیست. سناریوی ارتقا در این مرحله نصب مجدد همان نسخه ساخته‌شده است؛ آزمون مهاجرت بین دو نسخه متفاوت نیازمند نگهداری یک installer نسخه قبلی به‌عنوان fixture انتشار است.
