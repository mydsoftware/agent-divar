# Agent Divar

سامانه دسکتاپ ویندوزی مدیریت سرنخ‌ها و کمپین‌های کسب‌وکار با رابط فارسی.

## وضعیت فعلی

این مخزن نقطه شروع توسعه مرحله‌ای Agent Divar است. نسخه فعلی شامل تعریف کمپین، بازکردن جستجو در دیوار، تنظیم بازه زمانی انتشار آگهی برای هر کمپین، ثبت دستی سرنخ‌های مجاز، مدیریت وضعیت پیگیری و خروجی Excel است. توجه: در نسخه فعلی انتخاب بازه زمانی ذخیره می‌شود؛ اعمال خودکار آن روی نتایج دیوار پس از پیاده‌سازی موتور دریافت و پردازش آگهی در فازهای بعدی تکمیل خواهد شد.

## اجرا در ویندوز

1. Python 3.10 یا جدیدتر را نصب کنید.
2. در پوشه پروژه اجرا کنید:

   ```powershell
   python -m pip install -r requirements.txt
   python app.py
   ```

   یا فایل `run_windows.bat` را اجرا کنید.

## قابلیت‌های نسخه پایه

- رابط گرافیکی فارسی با Tkinter
- تعریف و ویرایش چند کمپین
- جستجو بر اساس کد شهر و کلمات کلیدی
- تنظیم و ذخیره بازه تاریخ انتشار آگهی: همه آگهی‌ها، ۳ ساعت، ۱۲ ساعت، ۱ روز، ۳ روز و ۷ روز گذشته
- حفظ فیلتر تاریخ انتشار هنگام ویرایش کمپین و مهاجرت خودکار پایگاه‌داده‌های قبلی
- ثبت اطلاعات آگهی و راه تماس عمومی/مجاز
- ثبت وضعیت رضایت و مرحله فروش
- جلوگیری از ثبت لینک تکراری
- ذخیره‌سازی محلی با SQLite
- خروجی Excel راست‌به‌چپ با لینک قابل کلیک

## نقشه راه

توسعه در ۱۲ فاز انجام می‌شود: تثبیت هسته، موتور جستجو، دریافت و پردازش داده‌های مجاز، تحلیل هوشمند، CRM، ارتباط رضایت‌محور، کمپین‌ها، داشبورد، خودکارسازی، بسته ویندوز، لایسنس و انتشار.

## حریم خصوصی و قوانین پلتفرم

این نسخه استخراج انبوه اطلاعات شخصی و ارسال پیام تبلیغاتی سرد در چت دیوار را انجام نمی‌دهد. هرگونه اتصال به دیوار باید از مسیرهای رسمی و مجاز و مطابق مستندات و مجوزهای لازم پیاده‌سازی شود. پیام‌رسانی فقط در سناریوهای مجاز و با رضایت یا درخواست لازم انجام می‌شود.
