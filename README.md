# Agent Divar

سامانه دسکتاپ ویندوزی مدیریت سرنخ‌ها و کمپین‌های کسب‌وکار با رابط فارسی.

## وضعیت فعلی

این مخزن در حال توسعه مرحله‌ای است. نسخه پایه شامل تعریف کمپین، اجرای مرورگر زنده، بازکردن جست‌وجو در دیوار، ثبت دستی سرنخ‌های مجاز، مدیریت وضعیت پیگیری و خروجی Excel است.

**توجه:** موتور دریافت خودکار آگهی، تحلیل هوشمند، CRM کامل و گردش‌کارهای عامل هوشمند هنوز در نقشه توسعه هستند و نباید قابلیت پیاده‌سازی‌نشده به‌عنوان فعال معرفی شود.

## اجرا در ویندوز

1. Python 3.10 یا جدیدتر را نصب کنید.
2. در پوشه پروژه اجرا کنید:

   ```powershell
   python -m pip install -r requirements.txt
   python -m playwright install chromium
   python app.py
   ```

   یا فایل `run_windows.bat` را اجرا کنید.

## قابلیت‌های نسخه پایه

- رابط گرافیکی فارسی با Tkinter
- تعریف و ویرایش چند کمپین
- اجرای زنده و قابل‌مشاهده Microsoft Edge یا Chromium با Playwright؛ پروفایل ورود محلی در پوشه data/browser-profile حفظ می‌شود و کاربر می‌تواند مستقیماً با موس و کیبورد کنترل کند
- مدیریت چرخه عمر مرورگر، شامل اجرای مجدد و دکمه مستقل بستن مرورگر
- جست‌وجو بر اساس کد شهر و کلمات کلیدی
- تنظیم بازه تاریخ انتشار آگهی برای کمپین
- ثبت دستی اطلاعات آگهی و راه تماس عمومی/مجاز
- ثبت وضعیت رضایت و مرحله فروش
- جلوگیری از ثبت لینک تکراری
- ذخیره‌سازی محلی با SQLite
- خروجی Excel راست‌به‌چپ با لینک قابل کلیک

## نقشه توسعه

نقشه راه جامع در [docs/ROADMAP_FA.md](docs/ROADMAP_FA.md) قرار دارد. مسیر توسعه شامل این بخش‌هاست:

1. تثبیت معماری، پایگاه‌داده و ثبت رویدادها
2. موتور جست‌وجو و دریافت داده از مسیرهای رسمی و مجاز
3. تحلیل، امتیازدهی و مقایسه آگهی‌ها
4. CRM و مدیریت مشتری و پیگیری
5. ارتباط کنترل‌شده و رضایت‌محور
6. گردش‌کارهای عامل هوشمند و قابل توقف
7. داشبورد، گزارش و خروجی
8. بسته‌بندی و نصب ویندوز

## حریم خصوصی و قوانین پلتفرم

این پروژه برای استخراج انبوه اطلاعات شخصی، دور زدن محدودیت‌های پلتفرم یا ارسال پیام تبلیغاتی سرد طراحی نمی‌شود. اتصال به دیوار باید از مسیرهای رسمی و مجاز و مطابق مستندات و مجوزهای لازم پیاده‌سازی شود. پیام‌رسانی فقط در سناریوهای مجاز و با رضایت یا درخواست لازم انجام می‌شود. عملیات حساس باید قابل مشاهده، قابل توقف و ثبت‌شده باشد.

مراجع فنی:
- https://divar-ir.github.io/kenar-docs/
- https://divar-ir.github.io/kenar-docs/chat/users_conversations/
- https://divar-ir.github.io/kenar-docs/oauth/get_user/

## تحلیل آگهی و تطبیق با نیاز مشتری

ماژول `listing_analyzer.py` امتیاز تطبیق آگهی با معیارهای مشتری را به‌صورت قطعی و توضیح‌پذیر محاسبه می‌کند. معیارهای قابل‌مقایسه شامل بودجه، متراژ، تعداد اتاق، محدوده و امکانات هستند. داده‌های ناموجود از امتیازدهی حذف می‌شوند و اگر هیچ داده مشترکی وجود نداشته باشد، نتیجه «اطلاعات ناکافی» است؛ هیچ قیمت یا ویژگی مفقودی حدس زده نمی‌شود. مقایسه قیمت هر متر نیز فقط وقتی انجام می‌شود که قیمت و متراژ هر دو آگهی معتبر باشند.

اجرای تست‌ها:

```bash
python -m unittest discover -s tests -v
```

 
## ثبت مشخصات ملک و تحلیل تطبیق خریدار (فاز ۴)
- ثبت قیمت، متراژ، تعداد اتاق، محله و امکانات در کنار اطلاعات آگهی
- مهاجرت افزایشی پایگاه داده به نسخه ۳؛ داده‌های قبلی حفظ می‌شوند
- تحلیل آگهی انتخاب‌شده با بودجه، بازه متراژ، تعداد اتاق، محدوده و امکانات موردنیاز خریدار
- نمایش امتیاز، پوشش معیارها و دلایل هر معیار در رابط برنامه
- ثبت رویداد تحلیل در گزارش عملیاتی
- معیارهای خالی از امتیازدهی کنار گذاشته می‌شوند و در نبود داده مشترک نتیجه «اطلاعات ناکافی» است


## مدیریت خریداران و مقایسه آگهی‌ها (فاز ۵)
- پروفایل مستقل خریدار با سقف بودجه، بازه متراژ، تعداد اتاق، محدوده و امکانات موردنیاز
- ذخیره، ویرایش و حذف پروفایل خریدار
- انتقال معیارهای خریدار انتخاب‌شده به فرم تحلیل آگهی
- انتخاب چند آگهی و رتبه‌بندی آن‌ها با موتور تحلیل توضیح‌پذیر
- ارتقای پایگاه داده به نسخه ۴ با جدول مستقل خریداران و حفظ داده‌های قبلی
- راه تماس فقط در صورت داشتن مجوز/رضایت ثبت می‌شود؛ هیچ پیام خودکاری ارسال نمی‌شود


## تاریخچه تعاملات و یادآورها (فاز ۶)
- ثبت دستی تماس، پیام، جلسه و یادداشت برای پرونده خریدار یا سرنخ
- نگهداری زمان تعامل، شرح و نتیجه و ارائه تابع تاریخچه مرتب‌شده از جدید به قدیم
- ثبت یادآور با موعد، اولویت و ارتباط با خریدار یا سرنخ
- وضعیت‌های یادآور: در انتظار، انجام‌شده و لغوشده؛ هر یادآور فقط یک‌بار تعیین تکلیف می‌شود
- فهرست و فیلتر یادآورهای سررسیدشده از طریق لایه مدیریت پیگیری
- ارتقای افزایشی SQLite به نسخه ۵؛ داده‌های قبلی حفظ می‌شوند
- این فاز هیچ تماس یا پیامی ارسال نمی‌کند؛ تعاملات فقط پس از ثبت دستی کاربر ذخیره می‌شوند

تست‌های این فاز در `tests/test_followup_manager.py` قرار دارند و همراه کل مجموعه با دستور زیر اجرا می‌شوند:

```bash
python -m unittest discover -s tests -v
```
